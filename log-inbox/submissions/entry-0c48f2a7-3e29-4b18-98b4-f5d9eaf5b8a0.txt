AL Cloud architecture correction: combine fresh Work wake invocations with delegated subagent workers.

The unattended runtime should use a fresh event-triggered Work invocation only as a thin bootstrap/orchestration layer, not as the long-running intelligent gameplay worker. On wake, the Work run reconstructs Director context from durable project state, reads due/unacknowledged work, selects the appropriate conceptual role, and immediately delegates the bounded gameplay task to an appropriate subagent/model. The delegated worker performs the game task through the purpose-built AL Cloud control interface, returns compact operational results, and the bootstrap Work run updates durable state, acknowledges completed wake items, and schedules the next wake before exiting.

The interactive main Director chat remains the human-facing planning/policy surface and is not itself woken by Scheduled Tasks or event triggers. Its goals/policies must be persisted externally so fresh Work invocations can reproduce the same Director intent.

This combines the two prior ideas: fresh Work runs provide reliable timer/event entry points, while subagent delegation minimizes how much reasoning/computer-use workload the Work bootstrap itself performs. Model/effort selection can be role-specific, e.g. cheaper workers for deterministic/low-risk tasks and stronger workers for ambiguous strategic decisions, but actual usage accounting, subagent model availability, and computer-use/tool compatibility still need empirical validation before relying on cost savings.

Next concrete test should validate the combined pattern end-to-end: event-triggered Work run -> load durable state -> spawn delegated worker with explicit model/effort -> worker reads one bounded AL Cloud observation/task via purpose-built interface -> returns structured result -> Work updates/acknowledges state. Measure whether this consumes substantially less Work usage than performing the same task directly in Work and confirm the delegated worker can access the required AL Cloud plugin/tools.
