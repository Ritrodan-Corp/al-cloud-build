2026-09-14 AL Cloud automatic GitHub wake bootstrap armed

Armed a temporary self-cleaning bootstrap path in Ritrodan-Corp/ALcloud@vm-control to validate Cloudflare timer -> GitHub PR comment once the Worker runtime credential exists. `runtime-wrapper.js` now adds a scheduled handler that does nothing until `WAKE_MODE=github` and `GITHUB_TOKEN` is present. On the first eligible minute it checks existing wake events and, only if no `__github_wake_bootstrap__` event exists, schedules one five seconds ahead. The event then uses the normal Durable Object alarm and GitHub comment dispatcher targeting ALcloud PR #1. Because the bootstrap reason is persisted in the wake list, later cron invocations do not create duplicates. Added a temporary one-minute cron trigger solely for this bootstrap validation. Plan: once the GitHub wake comment is observed successfully, remove the cron/bootstrap handler and leave only the normal Director-scheduled wake path.
