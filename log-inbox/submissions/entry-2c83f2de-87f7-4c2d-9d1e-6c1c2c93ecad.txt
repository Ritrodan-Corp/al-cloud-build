Planning checkpoint: user asked for an easier way to access the browser controller without manually using PowerShell. Recommended direction is a one-click Windows launcher that starts the existing IAP tunnel in the background, waits for localhost:8766, then opens the browser controller. This preserves the current localhost-only service and IAP security model. Longer-term alternatives like Tailscale/Cloudflare would reduce local tooling but add external networking dependencies and are not preferred for the immediate path.
