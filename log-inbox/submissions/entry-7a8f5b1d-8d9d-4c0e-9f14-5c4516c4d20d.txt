Oracle PAYG VM creation-profile justification and network refinement.
Reviewed the current AL Cloud project state against current Oracle documentation. The project itself calls for first Oracle validation on one VM.Standard.A1.Flex at 4 OCPUs / 16 GB and requires preservation of the qualified 39-bit/4-KiB ARM64 compatibility path, private ADB/controller surfaces, bounded storage, and validation before GCP is displaced.
Current Oracle documentation confirms A1 Flex is Ampere ARM, paid tenancies receive the first 3,000 A1 OCPU-hours and 18,000 GB-hours per month free, Ubuntu 24.04 aarch64 platform images are current, and 200 GB combined Always Free boot/block storage remains available in the home region. A 100 GB boot volume leaves half that storage pool unallocated.
Networking recommendation refined from the earlier public-subnet/ephemeral-IP proposal to a private regional subnet with no public VM IP, OCI Bastion for time-limited SSH/port forwarding, NSG rules scoped to the workload, and outbound internet through an appropriate gateway for package/container retrieval. OCI Bastion is documented as free. This better preserves the existing project's no-public-control-surface boundary.
No OCI connector is installed in ChatGPT. Plugin directory search found no Oracle Cloud/OCI integration. The only connected Remote Desktop Commander device is the existing GCP VM and it is currently offline, so this chat cannot directly operate the OCI console at present.
