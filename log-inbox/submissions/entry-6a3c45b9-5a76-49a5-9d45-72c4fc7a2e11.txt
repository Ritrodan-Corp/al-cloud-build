AL Cloud architecture update, 2026-09-14: User supplied direct Work UI evidence resolving a prior uncertainty. The Work spawn-subagent interface explicitly supports optional `model` and `reasoning_effort` overrides, with available model overrides including `gpt-5.6-luna` (as well as Sol/Terra and others). The shown interface states that these overrides are available when limiting inherited conversation context via `fork_turns: "none"` or a positive number; with `fork_turns: "all"`, the subagent inherits the parent model/reasoning effort and overrides are unavailable. Consequence for AL Cloud: a Work/Sol Director can in principle delegate tightly scoped execution tasks to Luna within the same Work run. Remaining empirical questions are whether child agents inherit/receive the required connector/tool access (especially Remote Desktop Commander / future AL Cloud controls), what approval behavior applies in unattended scheduled/event-triggered runs, and how usage is accounted across parent and child agents. This supersedes earlier uncertainty that Work model-selectable subagents might not exist.
