One-click Windows launcher design pass: use the already-working `gcloud compute ssh` IAP path and hide/minimize it rather than switching to direct `gcloud compute start-iap-tunnel` for port 8766. The browser streamer remains intentionally bound to VM loopback (127.0.0.1:8766), so direct IAP TCP forwarding to instance port 8766 would require changing that security boundary. Launcher will detect an existing localhost tunnel, otherwise start the SSH local forward in the background, wait for /api/status, then open the browser controller. Cloudflare remains a possible future access layer, not part of this quick launcher.
