Windows launcher implementation step: added `windows-launcher/azl-cloud-launch.cmd` on `vm-control`. The launcher requires only the existing Google Cloud CLI and Windows curl. It first reuses an already-live localhost:8766 tunnel if present; otherwise it starts the proven `gcloud compute ssh --tunnel-through-iap` local forward in a minimized background cmd process, polls `/api/status` for up to 45 seconds, and opens `http://127.0.0.1:8766/`. Failure leaves a readable log under `%LOCALAPPDATA%\AzurLaneCloud\tunnel.log`.
