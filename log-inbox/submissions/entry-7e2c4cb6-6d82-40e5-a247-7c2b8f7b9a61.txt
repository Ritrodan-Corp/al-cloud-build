2026-09-14: Verified the model-delegation question rather than relying on assumption. Current OpenAI documentation shows that Codex can delegate from GPT-5.6 Sol to model-selectable subagents including Luna via multi-agent support, and the API has a multi-agent beta. For ChatGPT Work, the documented multi-agent mode is `ultra`; OpenAI states that Work ultra is available to Pro and Enterprise users, while Codex ultra is available to Plus and higher plans. The current Work help page does not document a general Sol->Luna subagent dispatch mechanism for ordinary Plus Work runs. Therefore the AL Cloud design should not assume that a Plus Work Sol task can internally summon a Luna worker. If low-cost child execution is desired on Plus, Codex or the API may provide the mechanism, but whether either can participate in the required unattended game-control workflow must be tested separately. No VM or Android state modified.
