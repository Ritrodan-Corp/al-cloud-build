2026-09-14 PDT | Cloudflare Builds API identifier clarification

Clarified the Cloudflare Workers Builds API setup after the dashboard failed to surface the vm-control branch. The Cloudflare account ID can be copied from Workers & Pages > Account Details or via dashboard search command "Copy account ID". The Worker name is the human-readable script name (intended: al-cloud-control), but the Builds API does not use that name directly for Worker-scoped endpoints; it requires the immutable Worker tag, exposed as external_script_id. The documented way to retrieve the tag is GET /accounts/{account_id}/workers/scripts and read the tag field for the target Worker.

Also corrected an earlier assumption about credentials: the build token selected in the Workers Builds UI is not the token used to call the Builds API. Cloudflare requires a separate user-scoped API token for the Builds API; for the planned branch-control update it needs Workers Builds Configuration: Edit and Workers Scripts: Read. The next user-side step is to provide the Cloudflare account ID, after which we can supply a one-shot local command to discover the Worker tag and production trigger UUID without exposing the API token in chat.
