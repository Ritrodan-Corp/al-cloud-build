Project direction clarified: next implementation lane is to get AzurLaneAutoScript (ALAS) working against the existing ReDroid Azur Lane runtime, then use it as the deterministic game-action layer for a regular ChatGPT conversation. Current verified gap remains a write-capable agent interface: /usr/local/bin/azl-agent currently exposes only read-only observe, while human browser control and broad RDC are not the intended specialist-facing gameplay API. ALAS source review confirmed it hard-enforces 1280x720 screenshots in module/device/screenshot.py and requests human takeover on unsupported resolutions, so the qualified 854x480 performance configuration will require either a controlled 1280x720 ALAS proof first or a screenshot/input coordinate adaptation layer before long-term low-resolution use. Proposed architecture is ChatGPT -> narrow ALAS/azl-agent commands -> ALAS deterministic perception/navigation/input -> ReDroid/Azur Lane, rather than giving the model arbitrary shell access.
