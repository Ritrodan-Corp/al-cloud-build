The 3-second sample was 29,498 bytes and contained exactly three Annex-B NAL units: SPS type 7 (18 bytes), PPS type 8 (6 bytes), and one IDR type 5 (29,462 bytes). This strongly suggests a live-player buffering edge case: if the Annex-B parser only releases a NAL after seeing the next start code, the final/only IDR remains buffered indefinitely on a static screen, yielding a black canvas at 0 fps despite valid H.264 data.
