Windows launcher packaging step: produced a user-downloadable bundle containing `Azur Lane Cloud.vbs`, `azl-cloud-launch.cmd`, and `README.txt`. Normal use is double-clicking the VBS wrapper for an invisible launch; the cmd file remains a visible fallback if VBScript is unavailable. The bundle preserves the tested localhost-only 8766 + IAP/SSH forwarding model and opens the browser automatically once `/api/status` responds.
