Proposed specification method for fixed-time scheduled chat agents. Define the first agent as a one-shot Daily Reset v1 routine and write each chore using the same contract: trigger/schedule, objective, prerequisites/required observations, allowed decisions, ordered actions, success/postcondition checks, bounded in-run recovery, fail-closed conditions, side effects/resource policy, and reporting fields. Fill this contract chore-by-chore for login rewards, skill training, exercises, daily raids, hard attempts, dorm refill, and reset-time shops. Separate hard facts from policy choices still requiring user decisions. Do not assume retries or later rescue runs. After the written spec is agreed, convert it into a concise scheduled-agent prompt and qualify it first on harmless observation/navigation before enabling irreversible/resource-spending actions.
