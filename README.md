# al-cloud-build

Build, automation, infrastructure, and experiment source for AL Cloud.

This repository contains the technical material needed to reproduce builds, run supported GitHub Actions workflows, and maintain generic infrastructure helpers.

## Repository scope

Keep this repository focused on reproducible technical code, build definitions, generic infrastructure patterns, and experiment provenance.

Do not commit credentials, personal identifiers, account-specific configuration, live deployment endpoints, cloud resource identifiers, device/account IDs, or other deployment-specific secrets.
